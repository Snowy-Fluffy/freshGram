# freshGram

[ [English](README.md) | Русский ]

freshGram — форк [Telegram Desktop](https://github.com/telegramdesktop/tdesktop), который объединяет
оформление и кастомизацию в стиле Material Design из [materialgram](https://github.com/kukuruzka165/materialgram)
со всеми возможностями [AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop).
Работает на основе [Telegram API][telegram_api] и защищённого протокола [MTProto][telegram_proto].

Исходный код опубликован под лицензией GPLv3 с исключением для OpenSSL, текст лицензии находится [здесь][license].

## Возможности

### Из AyuGram Desktop

- Полный режим призрака (гибко настраивается)
- История сообщений: правки (чужие и ваши) и удалённые сообщения хранятся в локальной базе, для которой автоматически делаются резервные копии (при повреждении базы восстанавливается последняя рабочая копия)
- Защита от удаления сообщений (anti-recall)
- «Peek last seen» в профиле пользователя (без Telegram Premium): на секунды добавляет его в исключения «Last seen & online», читает его точный статус и возвращает ваши настройки приватности; результат выводится отдельной строкой в профиле и рядом со статусом в верхней панели чата и в шапке профиля, например «last seen recently (peeked: last seen yesterday at 11:27 PM)»
- Секретные чаты в основном списке чатов (включаются вручную: Настройки - AyuGram - Enable secret chats, нужен локальный пароль): форматированный текст, ответы, фото, файлы, статичные стикеры и GIF, голосовые и кружки через родное поле ввода, таймеры самоуничтожения, «печатает» и отметки прочтения, пересылка, шоты сообщений, родной просмотрщик медиа, картинка ключа и hex для сверки. Завершённые чаты остаются в списке, настоящие уведомления показывают только «Secret chat» и «New secret message», запросы, пришедшие при закрытом freshGram, подхватываются после перезапуска. Ключи, сообщения и вложения шифруются ключом, производным от ключа локального пароля, вместе с метаданными чата и с привязкой к чату и сообщению; снятие пароля и выход из аккаунта удаляют секретные чаты, а резервные копии базы хранят секретные данные только в самых новых снимках, ссылки не превью-ятся через серверы Telegram
- Системные сообщения (например, «пользователь вступил») сохраняются при удалении так же, как обычные
- Чаты и каналы, которые удалил собеседник, из которых вас исключили или которые вы удалили сами, остаются в списке чатов вместе с сохранёнными сообщениями (полностью чат удаляется повторным нажатием «Удалить»)
- Настройка шрифтов
- Режим стримера: на всех платформах прячет фото, видео, аватарки, юзернеймы, ID, номера телефонов и даты регистрации за спойлерами, а на Windows и macOS ещё и скрывает всё окно от захвата экрана (обе части настраиваются там)
- Локальный Telegram Premium
- Переводчик
- Предпросмотр медиа и быстрая реакция по force click (macOS)
- Улучшенное оформление
- Выбор иконки приложения

Подробное описание этих функций смотрите в [документации AyuGram](https://docs.ayugram.one/desktop/).

### Из materialgram

- Собственные темы Material You (Google Day и Google Dark, применяются при первом запуске)
- Шрифт **Google Sans** везде (кроме арабских символов, для них используется **Vazirmatn**)
- Material-иконки вместо стандартных (отключаются в настройках внешнего вида AyuGram, нужен перезапуск)
- Скруглённые фото и видео, сообщения без «хвостиков» и старые отступы (настройка «Message Rounding and Tail» в настройках чатов AyuGram возвращает классические скругления и хвостики)
- Цветной фон ответов с настраиваемой прозрачностью
- Убрана обводка у «больших эмодзи»
- Меньше заглавных букв в интерфейсе
- Перемотка круглых видео
- Удаление более 100 сообщений за раз
- Копирование ID автора набора стикеров и инкремента
- Упоминание нескольких пользователей сразу правым кликом
- Кнопки меню администраторов и журнала действий над списком участников
- Копирование юзернеймов в виде @example
- Фото из @gamee в списке фото профиля (опционально)
- Убрана задержка при записи голосовых сообщений
- Платформа веб-приложений сообщается как «android» (включено по умолчанию, отключается в настройках AyuGram)
- Заменены все звуки
- Меньшее сжатие JPEG (94–95% для фото, 100% для обоев)
- Уменьшены минимальный размер окна и минимальная толщина кисти в редакторе фото
- Уменьшены некоторые задержки (например, при открытии предпросмотра чата)
- Увеличена скорость загрузки
- Улучшена анимация спойлера
- Улучшено меню набора стикеров
- Улучшен экспорт чатов (10000 сообщений в одном html-документе и более быстрая загрузка файлов)
- Улучшен битрейт голосовых сообщений
- Скрытие номера телефона в профиле и настройках
- Больше недавних стикеров (по умолчанию без ограничения)
- Примерная дата создания аккаунта и датацентр в профиле (опционально)
- Датацентр и исходная дата фото/файла
- Платформа, с которой отправлено фото, в просмотрщике медиа
- Больше информации об уникальных подарках

## Значения по умолчанию

Там, где AyuGram и materialgram решают одну и ту же задачу, freshGram использует реализацию AyuGram,
а внешний вид materialgram задаёт как значение по умолчанию соответствующей настройки AyuGram
(например, «хвостики» сообщений убраны, а недавние стикеры не ограничены).

## Сборка

* [Windows 64-bit](docs/building-win-x64.md)
* [macOS](docs/building-mac.md)
* [GNU/Linux через Docker](docs/building-linux.md)

Для сборки нужны ваши собственные `api_id` и `api_hash` Telegram, см. [API credentials](docs/api_credentials.md).

### GitHub Actions

1. Добавьте секреты репозитория `API_ID` и `API_HASH`.
2. Один раз запустите workflow `Build environment`, он соберёт образы с библиотеками для x86_64 и aarch64 и отправит их в GitHub Packages.
3. Workflow `Build` собирает Linux x86_64 на каждый push и pull request и выдаёт `freshGram-linux-x86_64.tar.gz`, `freshGram.pacman` (пакет Arch Linux, ставится через `pacman -U`) и `freshGram.flatpak` (ставится через `flatpak install --user freshGram.flatpak`). Он же собирает Linux aarch64: `freshGram-linux-aarch64.tar.gz` и `freshGram-aarch64.*` (пакета pacman для aarch64 нет).
4. Workflow `Build Windows` и `Build macOS` запускаются на каждый push и вручную и выдают `freshGram.exe` (и `freshGram-windows-portable.zip` с папкой `TelegramForcePortable`, которая хранит все данные рядом с exe) и `freshGram.dmg` (подпись ad-hoc, открывать правым кликом - Открыть). Windows собирается под x64 и ARM64, файлы ARM64: `freshGram-arm64.exe` и `freshGram-windows-arm64-portable.zip`.
   Первый запуск собирает все библиотеки и может занять больше одного запуска: готовая часть кэшируется, поэтому запускайте workflow повторно, пока он не пройдёт.
   Для релиза запустите любой из трёх вручную с `release_tag` (например `v7.2.10`) или запушьте тег `v*`, все файлы прикрепятся к релизу.

Порядок слияния с upstream описан в [docs/upstream-merge.md](docs/upstream-merge.md).
Автообновление по умолчанию отключено, так как у freshGram нет сервера обновлений.
